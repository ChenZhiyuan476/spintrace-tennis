# SpinTrace

> A retro, physics-driven tennis game built with C++ and SDL3, where mouse-drawn strokes control power, direction, height, and spin.

SpinTrace 是一款不依赖商业游戏引擎的复古网球原型。玩家通过鼠标轨迹直接控制击球方向、出射高度和旋转，并通过按住左键决定力量。游戏逻辑使用 C++20，窗口、输入、音频和 2D 绘制使用 SDL3；macOS 版本明确请求 Metal 渲染器。

当前仓库内置通用架构的 `SDL3.framework`，在 macOS 上不需要另外安装游戏库。项目仍处于开发阶段，玩法、数值和界面可能继续调整。

## 运行

需要 macOS 11 或更高版本，以及 Xcode Command Line Tools。

```bash
./run.sh
```

也可以只构建：

```bash
./build.sh
open build/TennisGame.app
```

生成的应用位于 `build/TennisGame.app`。

启动后直接进入比赛，当前不启用主菜单和关卡流程；所有技巧默认开放，设置统一放在 `Esc` 暂停菜单中。

只测试不依赖SDL的物理、输入数据与成长系统：

```bash
./test.sh
```

## 操作

- `WASD`：移动
- `Esc`：暂停或继续；教程、挥拍映射、规则和记分设置都在暂停菜单中
- 按住 `Shift`：冲刺；松开恢复普通跑动
- 对手击球瞬间按鼠标右键：垫步，基础移动速度提高 15%，效果持续到下一次击球
- 发球时按鼠标右键：抛球；抛球后立刻按住左键蓄力并绘制轨迹，约 0.48 秒蓄满；发球不使用力度锁定，松开左键会立即挥拍，一直按住时自动击球会在球下降并刚离开绿色区时出手
- 球仍在手上时直接按住左键蓄力、绘制并松开：下手发球，不需要抛球
- 按住鼠标左键蓄力并绘制挥拍轨迹：球进入玩家绿色击球区会自动击打；如果只经过黄色困难区，则在即将离开黄区时自动补救击打。自动击球开启时，提前松开会锁定当前力度和轨迹，等待自动接触时机；关闭自动击球时，松开仍会立即尝试击球
- 左键按住时间控制总力度，回合球静止时约 0.85 秒蓄满；普通跑动时使用 45% 的蓄力速度，冲刺时完全无法蓄力，因此停稳准备仍然更容易打出满力；轨迹速度不再改变力量
- 轨迹相对起终点连线向上或向下弯曲：控制上旋或下旋
- 轨迹向左或向右弯曲：控制侧旋方向与转速
- 轨迹越接近直线，越多挥拍能量分配给平击推进；弯曲越大，越多能量分配给旋转
- 起点到终点的水平位移以逻辑像素一比一移动落点：向右画 80 像素，瞄准点就从球场中心向右移动 80 像素；到达当前单打线、双打线或自由场地的安全边缘后才截断。垂直位移决定出射高度
- 正手/反手：根据球在身体左右侧自动选择

挥拍画笔按系统当前识别的击球类型变色：底线球为青蓝色、发球为金黄色、截击为薄荷绿色、前场球为橙色、高压为红色。暂停菜单的挥拍测试和 `CONTACT ASSIST` 最近一拍轨迹使用同一套颜色，因此可以直接确认实际采用了哪一类映射。

暂停菜单的 `STYLE` 页面可以分别关闭左下记分牌、右侧 `CONTACT ASSIST` 和整组左上角信息。关闭左上信息不会隐藏正在绘制的鼠标挥拍轨迹。该页面按 `BOUNCY HARD`（弹性硬地）、`CLAY`（红土）、`GRASS`（草地）、`FAST HARD`（高速硬地）的顺序提供四套原创场地预设：两套硬地分别使用深浅蓝无限地面与蓝内绿外地面；红土和草地的界内外底色一致；草地使用更浅、更低饱和度的自然绿色，并在无限地面和右侧小地图上绘制竖向割草条纹，主画面条纹沿球场纵向透视线共同向消失点收束。初始默认使用 `BOUNCY HARD`。

`CLAY` 会根据真实运动事件生成轻量像素尘土：球触地时，粒子数量和向前喷散程度由垂直撞击速度与水平球速共同决定；玩家和电脑跑动时，尘粒从移动方向后方按脚步节奏扬起，冲刺会稍密、稍高。粒子拥有独立的平面速度、高度、重力、阻尼与淡出时间，切换到其他场地时立即清理。`SurfaceEffectProfile` 将粒子类型、颜色、落地倍率和跑动倍率保存在场地档案中，后续可以使用同一接口增加草屑或其他地面效果。

`GRASS` 只在较强落地或持续跑动时偶尔生成一小片黄绿色草屑，数量约为红土尘粒的一成。双方实际跑动路径会写入64×96格的磨损场，但显示时会把全部网格点组成一张带顶点透明度的连续三角网格，由显卡在相邻点之间平滑插值，不再逐格或逐圆绘制，因此不会暴露横向行列。磨损积累速度降低为上一版的24%；单次经过几乎不可见，需要明显更多的重复跑动、冲刺和变向才会逐渐形成黄绿色磨痕。全屏改用保持比例的 `OVERSCAN`：填满屏幕高度并只裁掉外场最左右侧的少量区域，不再生成无法绘制条纹的底部 letterbox。

画轨迹时，左上角会实时显示球种、力度、上下旋、侧旋、过网高度和平滑度。最近击球不再占用左侧画面，只在右侧 `CONTACT ASSIST` 底部保留最后一拍的轨迹、力度、出射高度 `H`、准确度、旋转和击球前体能；`V` 表示上下旋转而不是出射高度。

右侧 `CONTACT ASSIST` 使用深灰和米白像素面板，并整体靠近画面顶部；其中的小地图会同步当前赛事配色。高度尺使用没有格线和黑色外框的连续色带，并与缩小版完整球场图等高；普通绿色击球区约为 0.55–1.42 米，高压球在约 1.88–2.10 米有一小段绿色甜区，两者之间保持黄色的困难击球区。面板不再显示 `FULL COURT` 状态说明，只保留小地图、高度、紧凑蓄力条和最近一拍数据；冲刺中蓄力条会显示 `CHARGE LOCK`。所有教程文字都移入暂停菜单。

主镜头采用较低的转播角度，球的高度投影和吊高弧线经过收紧，可以直接根据球和影子的距离判断球高，不绘制影子到球的辅助线。球员、电脑、裁判、观众和网球都使用阶梯状像素椭圆阴影；人物阴影向脚下偏移，避免被圆形角色完全遮住。远端球员和球先绘制，球网居中绘制，近端对象最后绘制，因此球网遮挡会随球穿越球网正确切换。

场上双方使用更圆润的红蓝像素圆形标记，并让球心稍微离开地面，使角色与阴影的层次更清楚。场馆美术暂时保持极简：不绘制观众席或练习围栏，当前赛事的外场地面向画面四周无限延伸，从而完整保留双方底线后的跑动空间。比赛模式仍保留坐在简洁像素裁判椅上的裁判；练习模式隐藏裁判和椅子。椅子只保留座面、由阶梯像素块组成并向场外后倾的靠背、后支撑和一根带灰色踏步短线的前腿。球网保留像素风格，球场两端绘制标准底线中点短线。击球时仍会记录真实接触位置，并加入约 45 ms 的击球停顿和像素爆点。成功垫步会用约 0.22 秒完成一次短促的上移和落下，同时保留约 1.35 秒的移动体能优惠。发球和普通回合共用右侧蓄力条；轨迹决定方向与旋转，按住时间决定力量。启用自动击球时，回合中松开左键会冻结当前蓄力与轨迹，右侧显示 `POWER LOCK`，随后由接触辅助绿黄区触发；发球不锁定，松开立即挥拍，一直按住则在抛球下降并离开绿区时自动出手。网前截击通过球拍碰撞模型继承约 38% 的来球水平速度，使借力截击更有威力。

按 `Esc` 会打开与 `CONTACT ASSIST` 使用同一像素字体、细边框和配色的半透明暂停界面。一级菜单使用在面板中水平居中的纵向纯文字选项，悬停时变色，不显示额外选择提示；外观入口命名为 `STYLE`。`CONTROLS` 二级页支持从屏幕任意位置按住左键开始测试轨迹，不再限制起点位于中央方框，并实时显示力度、方向、出射高度、上下旋、侧旋、平击分配和平滑度。`AUTO HIT` 可以随时关闭；关闭后绿区与黄区只提供视觉参考，回合与发球都由玩家松开左键触发。比赛画面不绘制预测落点或预测曲线，玩家只根据实际来球和击球辅助判断时机。

`CONTROLS` 右上角的 `MAPPING SETTINGS` 可以分别选择 `GROUNDSTROKE`、`SERVE`、`VOLLEY`、`FRONT COURT` 和 `SMASH`。五类默认映射已收拢到接近的力度、方向、旋转和高度响应，切换类型不会再造成突兀的出球差异。系统先按球的状态分类：高于 1.72 米优先判高压；未落地且不是发球接发阶段的球判为截击；落地后且球员进入发球线后约一米才判为前场球；其余使用普通击球。高度输入以水平手势为零点，约每 42 像素上下位移改变 10% 原始高度。回合中的向下范围由离网距离连续决定：底线及底线外最低为 0，接近发球线逐渐允许轻度下压，越靠近球网开放越大的负高度；不再仅由“截击/前场/高压”名称突然切换。击球误差不会把明确的向下指令反转成向上出球。上手发球使用独立且较窄的安全范围，下手发球保留最低向上弧线。

规则与记分完全分离。规则页的 `PLAY MODE` 也独立于具体规则：`MATCH / OFFICIALS` 显示裁判与裁判椅；盘赛每盘奇数局结束后直接记录换边状态，让随球员旋转的转播镜头把固定裁判椅交替投影到画面左右两侧，不再显示额外文字或举牌提示。`PRACTICE / CLEAN` 隐藏这些场边元素，但保留当前发球、边界、弹跳和发球权设置。`MATCH PRESET` 会恢复比赛展示并启用严格发球、单打边线、标准两跳和轮流发球；修改任何具体规则后自动变为自定义：

- 发球规则开启：限制一区/二区站位、检查斜线发球区，并允许一发和二发；第二次失误才丢分
- 发球擦到网带或网面后，若第一落点仍进入正确发球区则判 `LET`，保持当前一发/二发次数并重新发球；擦网后落出发球区仍按普通发球失误处理
- 发球规则关闭：站位自由，不检查发球区；球真正越网后才转为普通回合，未越网可以继续重发
- 边界可选单打线、双打线或完全无出界
- 弹跳可选标准第二跳结束，或持续弹跳直到理论反弹高度低于最低击球高度
- 发球权可选每分轮流、始终玩家或始终电脑；电脑发球使用同一套发球和失误状态机

对方发球时，玩家会自动站到本方底线附近、与斜线发球区对应的左侧或右侧四分之一位置；一区和二区切换时接发站位也随之切换。

左下角使用接近真实电视转播比例的纤细双行比分牌，并向上离开窗口底边；两行保持完全等高且不绘制中间横线，所有数字按字符宽度在格子中居中，发球方在姓名前显示双斜线。比分牌会随场地预设切换：红土保留深绿、亮绿和米白；草地只使用深紫、浅紫和白色；两套硬地使用彼此不同、且与地面蓝色有明显区分的蓝色组。无限记分和抢分模式只在姓名后显示一列分数；盘赛模式会为每个已结束的盘追加一列双方局数，然后显示当前盘局数和当前局的 `0 / 15 / 30 / 40 / AD`。左上角从上到下依次排列稍加宽的体能条、黄色回合与正反手状态、白色球速与旋转数据，并使用“体能最大、黄色状态次之、白色数据最小”的三级字号；垫步提示位于其下。挥拍过程中会暂时隐藏正反手与垫步文字，为实时轨迹数据让出位置。HUD 不再使用全屏专用的固定偏移：每帧根据实际输出尺寸和 `OVERSCAN` 裁切范围反算可见逻辑边界，左侧信息与比分牌锚定可见左边缘，`CONTACT ASSIST` 锚定可见右边缘，并统一保留安全边距，因此窗口缩放、普通窗口和不同比例的全屏显示会自动重新布局。

普通跑动目标速度约为 5.2 m/s，按住 `Shift` 后的冲刺目标速度约为 7.4 m/s，分别对应网球运动员的常规场上移动和短距离全力启动。速度不再瞬间跳变：硬地约以 35 m/s² 启动、40 m/s² 制动；红土约为 28 / 24 m/s²，因此最容易出现短暂滑行；草地约为 31 / 29 m/s²，抓地介于两者之间。为保持转播透视下前后与左右操作一致，屏幕投影补偿只改变世界坐标换算，不改变这些地面档案之间的相对差异。

普通移动每秒消耗约 7.5 体能，冲刺每秒约 18.5，静止时每秒恢复约 5.5；长回合会很难一直保持满速。成功垫步后基础移动速度提高 15%，增速持续到玩家下一次击球，移动体能消耗不获得折扣；等待电脑发球时也可以提前按右键完成垫步。体能降至 20% 以下时体能条变黄，移动速度和击球准确度开始连续下降；完全耗尽时移动速度约为正常值的 62%，体能条变红。电脑拥有一条不显示的同规格体力条，跑动、冲刺、发球和回击都会消耗体力，静止时恢复；低体力会降低其移动和出球速度并扩大落点误差，因此连续大角度调动可以迫使电脑力竭失误。每一分结束后双方体力都会立即补满；一发失误、擦网重发等尚未结束该分的情况不会补充体力。自动切换正反手也会消耗少量体能；每次有效击球至少消耗 4 点基础体能，并额外计算最终出球力量、蓄力程度和招式复杂度，因此满蓄力重击会在体力条上产生明显下降。蓄力期间体力条以橙色覆盖预计消耗区段、白线标出击球后的预计剩余值，并显示预计消耗数字。体能参数集中在 `StaminaTuning`，蓄力速度与两个辅助开关集中在 `ControlSettings`，后续可以按球员、难度或关卡覆盖。

## 当前规则和物理

- 标准双打场地：23.77 m × 10.97 m，并绘制标准单打边线
- 网高：0.914 m；网球质量：0.057 kg；半径：0.0335 m
- `BOUNCY HARD` 提高硬地纵向恢复系数，弹跳更强但水平保速适中；`CLAY` 形成最高、最慢的球；`GRASS` 形成最低、最快的滑行球；`FAST HARD` 比弹性硬地保留更多落地水平速度，弹跳略低但节奏明显更快
- 三种地面只在人物与地面接触、网球触地时改变摩擦和恢复系数；空中的重力、空气阻力、Magnus 力与旋转衰减完全相同
- 速度档案集中在 `ShotSpeedTuning`。玩家力度使用非线性但可重复的速度曲线：约 25% / 50% / 75% / 100% 力度的平击初速分别约为 48 / 73 / 103 / 137 km/h，速度随机波动被压低到约 2.5% 误差系数，因而相同蓄力可以稳定复现。满力平发球约 173 km/h，理想击球高度提高到约 2.62 m
- `RULES` 菜单按 `EASY → NORMAL → HARD → EXPERT` 从低到高循环调整 AI，向左反向循环；难度会连续提高电脑移动速度和球速，同时缩小瞄准误差。普通难度底线初速约 70–92 km/h、发球约 133–162 km/h；困难难度约为 79–104 和 151–184 km/h，专家难度最高约 112 和 198 km/h
- 普通回球不再使用固定出射角，而是根据击球高度、目标距离和叠加来球动量后的实际出球速度反算低弧弹道，再叠加鼠标高度与旋转。这使高速 AI 瞄准界内时不会因为旧的慢速角度模型而频繁飞过底线
- AI 会以 120 Hz 向前模拟玩家来球、网带碰撞和第一次弹跳，并在自身移动速度与剩余时间允许的范围内选择约 0.55–1.62 米的优先接触高度；发球接发必须等待落地，已经位于前场时则允许合法截击。AI 出手前还会以更细时间步检查过网安全距离和第一落点，激进路线不安全时自动尝试更高仰角，最后改用中央上旋防守球。难度继续控制移动速度、回球速度和瞄准误差，体力不足仍会降低覆盖范围与回球质量
- 发球直接产生方向、三维初速度和旋转；回球则先生成本次挥拍，再通过独立球拍碰撞模型叠加反向来球动量与保留旋转，不根据目标落点反推飞行时间或修正过网高度
- 球网使用有限球半径检测实际接触高度：完全高于网带才算干净通过；擦到网带时根据触点深浅、入射法向速度、垂直速度和上下旋计算继续向前弹过或弹回，撞入网面则吸收绝大部分法向动量并落回击球方半场。普通回合擦网弹过后继续比赛，随后只按实际落点判定下网或出界
- 普通底线击球继承约 24% 来球水平速度，前场球约 28%，截击约 38%，高压约 10%；垂直来球速度以更低比例参与出射角，但玩家明确画出负 `H` 时，球拍碰撞不会再让下落来球的反向保留量把球重新抬成向上出射；不同招式仍设置 34–42 m/s 的三维出球上限
- 来球上下旋与侧旋在运动方向反转后以相反符号保留：底线球约保留 18% / 16%，截击约 34% / 30%，高压只保留 8% / 6%，再与鼠标轨迹产生的新旋转合成
- 之后以 120 Hz 逐帧积分重力、作用于三维速度的二次空气阻力，以及与飞行方向垂直的 Magnus 力
- 上旋加快下坠并增强落地后的前冲；切削减慢下坠并降低落地后的前冲
- 横向轨迹弯曲会产生侧旋，影响空中横移和落地后的横向速度
- 根据预计接触时的球高、是否落地和球员位置自动识别截击、前场球、高压、吊高和普通击球；截击不再依赖宽泛的前场边界，前场球只处理已经落地的短球
- 上手发球由右键抛球开始，抛球后约 0.48 秒蓄满；发球不保存锁定力度，松开左键立即尝试击球，持续按住时自动击球会在下降阶段刚离开绿色区时出手。发球目标默认留出更大的发球区内侧安全边距，方向、拍面和速度误差也小于普通强行击球；上手发球角度会随球速连续修正，避免高度输入在零点附近从飞长突然跳成下网。也可以直接松开左键下手发球。任何发球都必须先落地后才能接发，提前手动挥拍会提示等待落地，自动击球也会保持锁定直到第一次弹跳
- 轨迹不平滑、体能不足、击球点不理想或强行大力击球时，会直接扰动出射方位、拍面角度和球速；高速或重旋转来球会进一步放大不理想击球点与不稳定轨迹的准确度损失，程序不保证过网或落在场内
- 球飞过边线时不会立即判负；第一次触地才判断是否出界
- 球体接触边线即算界内；第二次触地后才结束回合
- AI使用同一套受力模型预测第一落点，明显出界或明显发球失误时会主动放球；接近边线的球仍会尝试回击
- SDL3 音效直接读取比赛物理数据：普通击球和发球分别使用自然球场 CC0 录音提供厚重主体，并叠加少量近距离职业录音补充清脆拍线瞬态；力度改变响度，旋转只叠加很轻的刷球层，准确率不足时对真实瞬态做低通处理。硬地、红土和草地落地以及擦网均以真实网球碰撞录音为基础，网带与网身再通过处理强度区分
- 120 Hz 固定物理更新，绘制跟随显示器垂直同步

## 项目结构

- `src/main.cpp`：应用入口、Metal 渲染器和固定时间步
- `src/game.hpp`：对外的游戏门面、共享状态、物理常量和各模块接口
- `src/game.cpp`：比赛生命周期、球员/AI更新、规则与物理事件编排
- `src/audio_system.hpp/.cpp`：独立的 SDL3 音效模块，加载真实击球录音并根据力度、旋转与准确率实时处理，同时按照碰撞速度、场地和触网类型生成其他短音效
- `assets/audio`：打包进应用的 CC0 职业击球、自然球场击球/发球、硬地/草地落地和擦网单次采样，以及完整来源和许可证说明
- `src/game_input.cpp`：SDL输入适配、挥拍轨迹分析、映射配置应用和玩家击球
- `src/game_menu.cpp`：暂停菜单点击、规则、记分和独立击球映射设置
- `src/game_render.cpp`：转播球场、球、HUD、击球记录和暂停菜单绘制
- `src/match_state.hpp`：球、比分、规则、位置与体能组成的可序列化比赛快照
- `src/player_input.hpp`：供键鼠、手柄、触屏和网络共同使用的输入命令
- `src/ball_physics.hpp/.cpp`：独立的球拍碰撞、网带/网面碰撞、来球动量与旋转继承、发射角、阻力、Magnus力、旋转衰减、落点预测与弹跳系统；`RacketImpactConfig` 提供各击球方式可独立调整的继承率与速度/旋转上限
- `src/gameplay_config.hpp/.cpp`：能力成长、击球区、握拍/动作、小球外观、HUD 开关、技巧、场地主题、三类地面物理，以及四套原创视觉、记分牌和场地粒子档案
- `src/progression_system.hpp/.cpp`：预留的教学关卡与成长模块，当前比赛流程不启用
- `src/scoring_system.hpp/.cpp`：独立的分、局、盘和比赛胜负推进，以及记分牌显示值
- `src/render_primitives.hpp/.cpp`：颜色与可复用的SDL像素绘制基础工具
- `src/vec2.hpp`：轻量二维向量
- `tests/core_tests.cpp`：不启动SDL即可验证物理确定性、来球借力、旋转合成、出球速度上限和关卡解锁顺序
- `test.sh`：编译并运行纯核心测试
- `vendor/SDL3.framework`：内置 SDL3 运行库
- `packaging/Info.plist`：macOS 应用信息
- `ARCHITECTURE.md`：模块依赖、扩展边界以及音效/教学/关卡/联机的接入原则

当前构建脚本面向 macOS。核心代码保持标准 C++；以后移植 Windows/Linux 时，只需换用对应平台的 SDL3 包和构建配置。

自由练习默认继续开放全部技巧并使用原有1.0属性，不改变当前手感。战役接口则提供从较弱基础能力开始的新玩家配置，依次通过平击、方向、上旋、切削、发球、截击、高压、侧旋、放短和吊高十个教学关卡；首次通关会同步解锁技巧，并提高力量上限、跑动速度、耐力、恢复、稳定性或击球容错。玩家握拍与挥拍动作可以独立改变力量、上下旋、侧旋和控制倾向。

角色外观使用 `BallAvatarStyle`，可以改变主色、辅色、尺寸以及纯色、中心点、条纹或双色图案。`HudSettings` 独立保存三个显示开关，`ControlSettings` 保存自动击球、回合/发球蓄满时间以及移动和冲刺蓄力倍率。`CourtPreset` 选择原创视觉预设，`CourtMaterial` 区分硬地、红土和草地；`CourtSurfaceProfile` 集中保存预设名称、场地与记分牌配色、条纹开关、移动速度比例、真实单位的加速/制动值和球的弹跳系数。未来新增室内地毯或自定义场地不需要改动比赛规则。`CourtTheme` 继续保留背景、场地、外场、线条、看台和观众配色接口，方便以后重新制作场馆美术；当前版本使用无限延伸的外场地面，不绘制看台、观众或围栏。
